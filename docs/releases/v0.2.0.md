## HeySnap v0.2.0

### 滚动截图

- 支持手动与自动纵向滚动截图，沿用原工具条复制、保存、Pin 和进入 Editor。
- 新增操作提示、固定的自动/停止按钮和右侧实时长图预览。
- 改善微小滚动与较快滚动的拼接，降低重复失配提示；短暂失配自动重试。
- 修复到底回弹和持续甩动造成的空白增长、末尾段落重复。

### OCR

- 框选工具条新增 OCR：本地识别选区文字，复制成功后退出截图；失败或没有文字则保留截图界面。
- Editor 的 OCR、复制、保存统一为同一个按钮组，OCR 提示简化为 “OCR”。
- 保留中英文、多行识别与空结果时的原剪切板；取消后不会写入迟到的识别结果。

### 安装与更新

下载 DMG 后将 HeySnap 拖入 Applications。支持 Apple Silicon Mac 上的 macOS 26 及以上；已有版本可通过应用内更新获取新版。
