# 猛烈底部弹性滚动

- 问题：页尾持续向下甩动产生大块空白，然后偶发重复末尾内容。
- 原因：弹性拉伸产生真实正向像素平移，上一轮反向判定无法识别其追加的空白；可靠前沿随后被拉伸帧污染。
- 方案：已确认静止的前沿，对新增纯背景/大块尾部背景暂不推进；仍允许后续有内容的真实滚动从原前沿继续。保持微滚动与性能。
- 验证：真实截图本机像素回放，公开生成文字页的多次正向拉伸/反向回弹/静止/恢复新内容；Core、AppKit、release 性能及正式构建安装。
- 验证结果：最新图本机三轮甩动回放保持原高度；Core release 37 项、AppKit 工作流与性能通过，新增弹性拒绝约 12ms。
- 状态：完成。Developer ID 构建、正式安装重启、签名与二进制一致性验证通过；实际 Chrome 交互由用户测试。
