# 统一快速标注与 Editor 箭头交互

## 目标

快速标注与 Editor 共用箭头绘制、曲线上锚点、拖动、移动、命中与手柄外观，消除独立实现导致的交互差异。

## 范围与约束

- 提取 AppKit 层共享箭头几何，UI 类型仅做适配。
- 中间锚点表示曲线上的中点，不直接暴露控制点。
- 保留 Editor 既有曲线模式、粗细、单/双箭头设置。
- 其他标注工具不扩大改动范围。

## 风险与验证

控制点允许位于图像外，不能强制夹到选区内，否则曲线不能穿过拖动位置。通过可运行渲染检查验证中点拖动、端点调整、整体平移、弯曲命中与 Retina 比例；构建、签名并安装后核对运行版本。
