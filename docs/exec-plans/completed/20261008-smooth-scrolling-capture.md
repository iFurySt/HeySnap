# 滚动截图流畅度与微小位移

- 目标：可靠追加一像素移动，降低手动采样延迟与自动大步停顿，保持低内存及主线程响应。
- 发现：每帧 SCShareableContent 枚举、重复图像采样、全位移全网格搜索、采样后固定等待；最小 2 像素和静止平均距离门槛漏尾段。
- 实现：会话复用过滤器；缓存可靠帧样本；小位移精确快路径与全分辨率行特征候选筛选；按采样周期补足等待；较小自动步长；预览限频且最终内容刷新。
- 验证：一像素/低对比度/连续微滚动/空白/反向/完整像素回归；Retina 大帧 release 性能基准；工作流退出末帧及预览回归；构建安装。
- 验证结果：Core 32 项通过；AppKit 回归验证微滚动末帧、自动底部停止与既有输出；2400×1600 release 基准连续一像素追加均值 4.79ms，400 次仅保留 5 块，预览中位数 0.36ms；普通位移缓存追加约 9–10ms。该基准不含系统采集开销，静止帧追加约 4.53ms，不声称每种操作均加速。
- 状态：完成。AppKit 最终回归及 Developer ID 构建通过；正式应用已替换、重启，签名和二进制一致性验证通过，旧安装保留回退副本。
