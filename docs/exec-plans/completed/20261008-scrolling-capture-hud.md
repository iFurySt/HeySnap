# 滚动截图 HUD 与实时预览

- 目标：进入时选区中央短暂显示中文黑色提示；底部中央自动/停止按钮；右侧等比长图预览。
- 约束：保留原工具条输出、手动默认、应用窗口排除、无底图过渡；不恢复浏览器自动实测。
- 实现：独立非激活浮层，提示与预览穿透；拼接条带后台生成最多 352×2200 小图。
- 验证：AppKit 按钮/布局/生命周期与输出回归、Core 拼接像素与预览、签名构建后安装。
- 验证结果：Core 28 项通过；AppKit 回归验证按钮 action、预览增长与等比封顶、右侧边界、完整长图输出和窗口关闭；渲染预览确认按钮图文可见。Developer ID 构建通过。
