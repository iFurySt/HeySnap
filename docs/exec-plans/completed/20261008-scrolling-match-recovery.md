# 滚动匹配容错与恢复

- 目标：减少短暂失配提示，支持较快滚动；保持错误拼接拒绝与性能界限。
- 发现：失配计为静止后降频，瞬时提示刷屏；全宽行特征受固定页头/侧栏干扰，搜索跨度仅 82%。日志显示常规位移之后持久失配，不能单凭日志断言都是速度问题。
- 实现：失败保持活跃采样；跨度到 95%（至少保留有效重叠）；原精确匹配失败才进行中心分带容错；持续失败提示防抖，自动先暂停事件重试再决定是否退出自动。
- 验证：大步、固定页头/侧栏、噪声与短暂帧变化、拒绝不相关图像、提示恢复/限频及性能；构建安装。
- 验证结果：Core 34 项通过；release 2400×1600 固定页头/侧栏恢复正确匹配约 24.7ms，小步 400 次仍保留 5 块。此基准不含系统采集/浏览器渲染。
- 状态：完成。AppKit 回归与 Developer ID 构建通过；正式应用已替换并重启，签名及二进制一致性验证通过。旧安装保留回退副本。
